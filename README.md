## 一句话说明

本文用**年报"管理层讨论与分析"文本**构造企业数字化转型程度指标（5 个维度、69 个关键词、
词频密度加权合成），并在 180 家制造业上市公司、2015—2023 年、1620 个企业—年份观测上
检验数字化转型对企业绩效（ROA）的影响。全文配套**可一键复现的代码与面板数据**。

> ⚠️ **学术诚信声明**：本稿为**预演稿**，语料是按真实年报统计特征生成的**仿真语料**
> （数据生成过程完全公开于 `code/s0_generate_corpus.py`），用来验证"文本测度 → 计量识别"
> 这一方法论链条是否走得通。因此**系数数值不具有直接的经济含义**，不能作为实证结论引用。
> 正式送审版只需把 `code/s0_generate_corpus.py` 换成巨潮资讯网年报抓取，
> `s1`—`s5` 全部脚本无需改动。

## 目录结构

```
code/            五步可复现流水线
  s0_generate_corpus.py   语料与真值数据生成（DGP，正式版替换为年报抓取）
  s1_clean.py             文本清洗（去噪、断句去重、否定语境处理）
  s2_tokenize.py          jieba 分词与关键词计数（最长优先匹配）
  s3_measure.py           五维词频密度测度（熵权法 / PCA 作为替代测度）
  s4_panel.py             企业—年份面板合成、平衡化、滞后项与工具变量
  s5_model.py             描述统计、信效度、基准回归、稳健性、异质性、内生性

data/            企业—年份面板（1620 × 22）与真值表、清洗摘要
```

## 主要结果（均可复现）

- **测度质量**：Cronbach's α = 0.714，分半信度 0.884，KMO = 0.795，
  第一主成分解释率 49.01%，与效标相关 0.876，与文档篇幅相关仅 −0.173（排除"篇幅驱动"）。
- **基准回归**：双向固定效应下 DigTrans → ROA 系数 **1.447\*\*\***（企业层聚类稳健 SE = 0.318，N = 1620）。
- **稳健性**：替换因变量（TobinQ 0.607\*\*\*、TFP 0.084\*\*\*）、替换测度（熵权法 1.739\*\*\*、因子得分 0.248\*\*\*）。
- **内生性处理**：行业×年度联合固定效应 1.417\*\*\*、未来一期因变量 0.931\*\*、剔除 2020—2022 年 1.425\*\*\*。
- **反向印证**：仅凭财务特征识别"高数字化"企业 AUC 仅 0.549，说明数字化程度必须依赖文本信息才能有效识别。
