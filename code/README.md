## 三、测度构造公式

```
式(1)  Den(d,i,t) = Σ_{k∈d} f(k,i,t) ÷ ( Char(i,t) / 1000 )        # 维度词频密度（每千字）
式(2)  Den(i,t)   = Σ_{d=1..5} W_d · Den(d,i,t)                    # 综合密度（基准等权）
式(3)  DigTrans(i,t) = ln[ 1 + Den(i,t) ]                          # 主指标
式(4)  DigTrans_ew   = ln[ 1 + Σ_d w_d · Den(d,i,t) ],  w 由熵权法确定
式(5)  DigTrans_pca  = 五维标准化密度的第一主成分得分
式(6)  ROA(i,t) = α + β·DigTrans(i,t) + γ′Controls(i,t) + μ_i + λ_t + ε(i,t)
```

词典共 **5 个维度、69 个关键词**：人工智能技术(17)、大数据技术(15)、云计算技术(11)、区块链技术(9)、数字技术应用(17)。

## 四、⚠️ 数据说明（重要）

**本仓库语料为仿真语料（synthetic corpus），用于预演阶段验证“文本挖掘 → 测度构建 → 面板回归”全流程的可行性。**

- 生成过程完全公开于 `code/s0_generate_corpus.py`：企业存在不可观测的真实数字化强度 θ（企业固定效应 + 时间趋势 + 行业效应 + AR(1) 持续性冲击），关键词提及次数服从以 θ 为均值的泊松过程；企业绩效由 θ 与控制变量共同决定。
- 该设计刻意保留了真实研究中的两个关键特征：**文本测度含测量误差**、**测量误差造成回归系数衰减偏误**，因此预演结果不能作为真实经济事实的证据。
- 正式研究与送审版论文将把 `s0` 替换为「巨潮资讯网年报 PDF 抓取 + 文本抽取」（`s1—s5` 无需修改），财务数据接入 CSMAR。

数据源（正式版）：
- 年报文本：巨潮资讯网 http://www.cninfo.com.cn
- 财务与治理数据：CSMAR https://data.csmar.com
- 政策文本：中国政府网 https://www.gov.cn
